These are the supplementary materials for "Comparative Politics and the Synthetic Control Method Revisited" by Joseph Francis.

The master file will run all the scripts in RStudio and re-generate the files in Results.

Datasets.R
This calculates the various versions of the dataset, using GDP per capita PPP, constant USD, with 44 different reference years.

Replication.R
Replicates Abadie et al.'s research design using their current price data and the real GDP per capita with 44 different reference years.

Gap_plot.R
Generates the gap plot for the 44 different versions of Abadie et al.'s research design using real GDP per capita.
